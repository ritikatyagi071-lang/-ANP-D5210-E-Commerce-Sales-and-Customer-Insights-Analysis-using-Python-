# E-Commerce Sales & Customer Insights Analysis

A beginner-friendly Data Visualization final project using **Excel, Python, and Power BI**.

## Project Overview
This project analyzes e-commerce transaction data to understand sales, profit, orders, customers, products, categories, regions, and monthly trends.

## Tools
- Microsoft Excel
- Python
- Pandas
- Matplotlib
- Power BI

## Dataset
The prepared educational dataset contains 600 e-commerce order records covering 2025.

## Project Structure
```text
data/             Dataset
python/           Python analysis script
visualizations/   Generated charts and analysis tables
powerbi/          Power BI dashboard instructions
report/           Final project report
screenshots/      Dashboard/chart screenshots
requirements.txt  Python dependencies
README.md         Project documentation
```

## Run Python Analysis
```bash
pip install -r requirements.txt
python python/ecommerce_analysis.py
```

Generated charts:
- Monthly Sales Trend
- Sales by Category
- Profit by Region
- Top 10 Products by Sales

## Power BI Dashboard
Import `data/Ecommerce_Sales_Customer_Insights_Dataset.csv`.

Recommended visuals:
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Profit by Category
- Profit by Region

Recommended slicers:
- Region
- Category
- Quarter

Save the completed dashboard as:
`powerbi/Ecommerce_Sales_Customer_Insights.pbix`
